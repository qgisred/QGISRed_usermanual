# 🚀 Bienvenido a QGISRed

**QGISRed** es un potente complemento para QGIS de acceso libre diseñado para facilitar la construcción de modelos hidráulicos de redes de distribución de agua, el análisis de resultados, la planificación de mejoras y la gestión eficiente del uso del agua a través del Gemelo Digital

Lo mejor de QGISRed es que combina las prestaciones de un **Entorno GIS** con la potencia de cálculo de **EPANET**, permitiendo manejar la información cartográfica para convertirla en  un modelo hidráulico capaz de reproducir los flujos, las presiones y la calidad del agua bajo cualquier hipótesis de trabajo. Además, alimentado por los datos de campo, permite también reproducir el estado real de la red a través de un gemelo digital.

### ¿Por qué usar QGISRed?

* **Herramienta de análisis hidráulico y calidad del agua.**   QGISRed reproduce en su totalidad y amplía las capacidades de cálculo de EPANET hasta la última versión 2.3. Es un entorno perfecto para la formación en hidráulica de redes
* **Georreferenciación completa**: Aprovecha todas las ventajas de QGIS para geolocalizar los elementos de la red, y superponerlos sobre cualquier fondo cartográfico, así como para interactuar con dichos fondos.
* **Gestión de Datos Sencilla**: Permite importar ficheros INP y ficheros SHP, georreferenciados o no,  con una estructura relacional sencilla e intuitiva. El modelo de datos de QGISRed es abierto y permite la interoperabilidad con otras aplicaciones.
* **Herramientas Especializadas**: Incluye utilidades para la depuración de la red, la asignación automática de longitudes, cotas y rugosidades, la asignación de demandas a los nudos, la gestión de escenarios y el análisis completo de los resultados sin salir de QGIS.
* **Gemelos Digitales**: Soporta elementos adicionales como acometidas, válvulas manuales y medidores para un nivel de detalle avanzado. La conexión de estos elementos con datos de campo permite reproducir el modo real de comportamiento de la red.&#x20;
* **Del mundo académico al profesional:** Desde construir esquemas sencillos de sistemas hidráulicos, a modelar la realidad para planificar actuaciones destinadas a mejorar el rendimiento hidráulico, la eficiencia energética o la calidad del agua, hasta realizar un seguimiento del comportamiento de la red a partir de datos reales para la toma de decisiones.
