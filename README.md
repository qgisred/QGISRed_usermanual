# Bem-vindo ao QGISRed 🚀

**QGISRed** é um plugin poderoso para QGIS projetado para facilitar a criação e análise de modelos hidráulicos de redes de distribuição de água.

A melhor coisa sobre o QGISRed é que ele combina o poder de um **ambiente GIS** com a precisão do **EPANET**, permitindo trabalhar com gêmeos digitais de qualquer complexidade.

### Por que usar o QGISRed?
* **Georreferenciamento completo**: Aproveite todas as vantagens do QGIS para localizar geograficamente seus ativos.
* **Gerenciamento de dados simples**: Use arquivos SHP e DBF com uma estrutura relacional intuitiva.
* **Ferramentas Especializadas**: Inclui utilitários para depuração de rede, gerenciamento de demanda e análise de resultados sem sair do QGIS.
* **Digital Twins**: Suporta elementos como conexões, válvulas manuais e medidores para um nível avançado de detalhe.
