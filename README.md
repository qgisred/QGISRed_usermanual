# Bienvenue sur QGISRed 🚀

**QGISRed** est un plugin puissant pour QGIS conçu pour faciliter la création et l'analyse de modèles hydrauliques de réseaux de distribution d'eau.

La meilleure chose à propos de QGISRed est qu'il combine la puissance d'un **environnement SIG** avec la précision de **EPANET**, vous permettant de travailler avec des jumeaux numériques de toute complexité.

### Pourquoi utiliser QGISRed ?
* **Géoréférencement complet** : Profitez de tous les avantages de QGIS pour géolocaliser vos actifs.
* **Gestion simple des données** : utilisez des fichiers SHP et DBF avec une structure relationnelle intuitive.
* **Outils spécialisés** : inclut des utilitaires pour le débogage du réseau, la gestion de la demande et l'analyse des résultats sans quitter QGIS.
* **Digital Twins** : prend en charge des éléments tels que les connexions, les vannes manuelles et les compteurs pour un niveau de détail avancé.
