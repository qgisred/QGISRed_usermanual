# 🧭 Quick Guide

Just getting started with QGISRed? Here are the basics to get you going.

1. **Create a Project**: Use [Project Manager](file.md) to organize your files.
2. **Add Data**: Import from `.SHP` or `.INP` files.
3. **Draw your Network**: Use the [Edition](../edition/README.md) tools.
4. **Simulate**: Get hydraulic results in seconds.

---
> 💡 **NOTE**:
> All data is saved in local files under an EPANET compatible relational structure.
