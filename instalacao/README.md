# 💻 Instalando QGISRed

QGISRed é um plugin gratuito para QGIS que pode ser instalado em apenas alguns minutos. Existem dois métodos: a partir do repositório oficial do QGIS (recomendado) ou a partir de um arquivo ZIP local.

---

## Pré-requisitos

| Requisito | Versão mínima |
|-----------|---------------|
| **Sistema operacional** | Janelas x64 |
| **QGIS** | 3.28 ou superior (compatível até 4.x) |
| **.NET Framework** | 4.8 |

> QGISRed está disponível apenas para **Windows**. O mecanismo de cálculo (dependências) é baseado em DLLs compiladas em .NET e não possui versão nativa para Linux ou macOS.
