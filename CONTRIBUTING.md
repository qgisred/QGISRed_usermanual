# Bem-vindo ao guia de contribuição do QGISRed

Obrigado por investir seu tempo contribuindo com nosso projeto!

Leia nosso [Código de Conduta](./CODE_OF_CONDUCT.md) para manter nossa comunidade acessível e respeitável.

Neste guia, você terá uma visão geral do fluxo de trabalho de contribuição desde a abertura de um problema.

Para obter uma visão geral do projeto, leia o [LEIA-ME](README.md).


## Problemas

### Crie um novo problema

Se você detectar um problema com o plugin, [pesquise se já existe um problema](https://github.com/neslerel/QGISRed/issues). Se não existir um problema relacionado, você pode abrir um novo problema usando um [formulário de emissão](https://github.com/neslerel/QGISRed/issues/new/choose) relevante.

### Comente um problema

Digitalize nosso [problemas existentes](https://github.com/neslerel/QGISRed/issues) para encontrar um que seja interessante para você. Você pode restringir a pesquisa usando `labels` como filtros. Se você encontrar um problema do qual possa participar, fique à vontade para comentá-lo e tentar nos ajudar.
