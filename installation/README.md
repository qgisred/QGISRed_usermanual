# 💻 Installation de QGISRed

QGISRed est un plugin gratuit pour QGIS qui s'installe en quelques minutes seulement. Il existe deux méthodes : depuis le référentiel officiel QGIS (recommandé) ou depuis un fichier ZIP local.

---

## Prérequis

| Exigence | Version minimale |
|-----------|---------------|
| **Système d'exploitation** | Windowsx64 |
| **QGIS** | 3.28 ou supérieur (compatible jusqu'à 4.x) |
| **.NET Framework** | 4.8 |

> QGISRed est uniquement disponible pour **Windows**. Le moteur de calcul (dépendances) est basé sur des DLL compilées en .NET et ne dispose pas de version native pour Linux ou macOS.
