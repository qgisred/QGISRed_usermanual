# Execution and Options

The first three actions on the Analysis bar control the simulation cycle: configure engine options, launch the simulation, and review the status report.

***

## Analysis options…

**Analysis bar → Analysis options…**

Opens the EPANET Engine Options dialog. It allows you to configure all the parameters that control how the hydraulic and quality simulation is carried out.

\*Analysis Options dialog: complete configuration of the EPANET engine.\*

### Configurable parameters

| Group          | Main parameters                                                                               |
| -------------- | --------------------------------------------------------------------------------------------- |
| **Hydraulics** | Flow units (LPS, GPM, CMH…), head loss formula (H-W / D-W / C-M), viscosity, specific gravity |
| **Quality**    | Type of quality analysis (none, chlorine, water age, source trace), reaction coefficients     |
| **Times**      | Total Simulation Duration, Hydraulic Time Step, Quality Time Step, Report Step, Start Time    |
| **Energy**     | Price of electricity, overall efficiency of pumps                                             |
| **General**    | PDA (Pressure Dependent Analysis) mode: activates local pressure dependent demand             |

> The Project Materials Table stores the roughness in D-W units (mm). If you change the hydraulic formula here, QGISRed will offer to automatically convert the existing roughness coefficients.

***

## Run model

**Analysis bar → Run model**

Launch the EPANET simulation with the options configured and load the results into the results panel.

### Process

1. QGISRed validates the project (active layers, no layers being edited).
2. Call the EPANET engine through the QGISRed toolkit.
3. When finished, it automatically opens the Results dock on the right of the screen and loads the calculated data.
4. The map updates the layer symbology with the values ​​of the first available time instant.

If the simulation detects problems (negative pressures, disconnected nodes, pumps in cavitation), the status report records them at a warning level.

### Progress Dialog Options

The progress dialog includes a **Pause** button (‖ icon). When pressed, the simulation stops at the end of the current time step and the icon changes to ▶. Pressing again resumes execution. The button disappears once the simulation has concluded.

The dialog also includes the **"Do not show this progress window again"** checkbox. If you check it and the simulation finishes successfully, subsequent runs will launch the calculation directly without displaying the dialog.

> ⚠️ **Exception for large networks**: if the product (number of nodes: junctions + tanks + reservoirs) × (number of calculation instants = Duration / hydraulic time step) exceeds **500,000**, the progress dialog is always shown in that run, even if the "Do not show this progress window again" box is checked from a previous run. Furthermore, in that case the box itself is hidden from the dialog, since the saved preference remains ineffective for the duration of that large network.

> To re-enable the progress dialog on networks that do not exceed that threshold, go to **Project Properties** and uncheck the _"Do not show progress window when running simulation"_ option.

> ⚠️ When the progress window is hidden, the system cursor changes to a standby cursor in all applications while the simulation is in progress. The cursor is automatically restored upon completion of the calculation.

### Status messages during execution

The progress dialog informs about the different phases of the calculation:

* **Saving results…**: indicates that the results are being written to disk after the hydraulic calculation is completed.
* If the result files (`.out`, `.hyd`) are **locked by another application** (for example, EPANET Desktop opened with the same project), the plugin detects it and notifies the user with a specific warning.

### Error handling

* If EPANET returns an error during the calculation, the content of the report (`.rpt`) is automatically displayed in the incident log without the need to search for it manually.
* Unexpected exceptions during the process are also captured and displayed in the log, avoiding silent failures.

***

## Results browser

**Analysis bar → Results browser**

Opens the results panel if a previous simulation already exists for the active project, without simulating again. If there are no results, it launches the simulation automatically.

It is equivalent to **Run model** but prioritizing the results already calculated: if the file `.out` exists and corresponds to the current project, it loads them directly. Useful to reopen the viewer after closing it without losing the results.

***

## Status report

**Analysis bar → Status report**

Opens the results panel directly to the **Status Report** tab, which displays the text report generated by the EPANET engine upon completion of the simulation.

The report includes:

* General mass balance of the network.
* List of nodes with negative pressure or out of range.
* Warnings of pumps operating outside their curve.
* Convergence status of the hydraulic calculation in each step.
* Summary of quality reactions (if quality was simulated).

> The status report is the first place to look when a simulation produces unexpected results or does not converge.
