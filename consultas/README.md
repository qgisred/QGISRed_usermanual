# 🗺️ Consultas y Análisis Espacial

La barra **Queries** agrupa las herramientas de inspección y consulta del modelo. A diferencia de las barras de Edición o Verificación, las herramientas de consulta son **de solo lectura**: no modifican ningún dato de la red.

> Esta sección se desarrollará próximamente. Consulta el [Resumen de barras de herramientas](../guia-rapida/toolbars.md#-queries--consultas) para una descripción breve de cada herramienta.
