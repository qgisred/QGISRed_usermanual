# 🔍 Queries

The **Queries** bar groups the interactive model query and inspection tools: search for elements by ID, exploration of individual properties, thematic maps, queries by conditions on attributes and network statistics. Unlike editing or analysis bars, these tools do not modify the model: they only interrogate and visualize what already exists.

\*Queries Bar: the five query and inspection buttons.\*

***

## Queries Bar Tools

All buttons belong to a single group without separators.

| # | Tool                       | Function                                                                     |
| - | -------------------------- | ---------------------------------------------------------------------------- |
| 1 | **Find elements by ID…**   | Locate one or more elements on the map by searching by their identifier      |
| 2 | **Element properties…**    | Shows in a floating panel all the properties of the element you click on     |
| 3 | **Thematic maps…**         | Generates a time-lapse colored layer of any hydraulic attribute of the pipes |
| 4 | **Queries by properties…** | Highlights on the map all elements that meet a condition on their attributes |
| 5 | **Statistics…**            | Calculates statistical distributions and histograms of network attributes    |
