# 📜 Changelog

Stay up to date with the latest QGISRed improvements.

### Version 0.19

**News**:

* Complete restructuring of the Statistics panel: new Setup/Report tabs, histogram with floating window and statistic selector on the Y axis, and second cross classification with results matrix.
* New display options in the Results panel: size proportional to value in nodes and pipes, and optional black outline in knot markers.
* Improved map labels: show item type and Id on the first line and value with units on the second.
* Map tooltips visible on all active layers managed by QGISRed, regardless of the layer selected in the legend.
* Quick time evolution directly from the Results dock, without having to open the Time Series panel.
* Improvements in the Time Series panel: new tank magnitudes (Volume and TankSpill), cursor synchronized with the value table, table copy with double header (name and unit), export and import of the chart configuration and support for multiple simultaneous windows.
* Simulation progress dialog with option to not be shown again (configurable from Project Properties).
* Improved simulation error handling: the EPANET report is automatically displayed in the log when an error occurs, and unhandled errors are logged instead of failing silently.
* Specific notice when results files are locked by another application.
* Demand Builder: restructuring of the patterns section by sectors with two exclusive modes (import external SHP / use project layer).
* Demand Builder: sector efficiency section with two work modes, and new options to correct category efficiencies and sector patterns to meet global objectives.
* Demand Builder: automatic distribution of missing demand percentages in section layers.
* New layer of isolated connections with non-zero demand generated by analyzing hydraulic segments.
* Distribution tree: The root node is identified with `NodeType = "ROOT"` in the resulting layer of nodes.
* Renaming identifier fields in the project's SHP layers (e.g. `Id` → `JunctionID`, `PipeID`, etc.). Projects created with previous versions remain compatible thanks to the inherited name table.
* Unassigned category renamed from "Undefined" to **"Uncategorized"** in the Demand Builder and layer legend.

### Version 0.18 (April 2026)
**QGIS Versions**: 3.28-4.99

*This version has been funded by [Inter-American Development Bank (IDB)](https://www.iadb.org/es) through contract C-RG-T4041-P001.*

**News**:
* Improvements in the Project Manager. New buttons to Move and Export projects, and new options to Rename projects.
* Identification of all layers managed by QGISRed using their own Id, instead of by name, which allows working in several languages.
* Review of map symbols, labels and notices associated with all layers managed by QGISRed.
* Greater integration of the Element Properties Editor, maintaining layer properties, and refreshing data in all affected windows, including the attribute table.
* Storage of the style of all the layers managed by QGISRed in .qml files at three levels: default, user level and project level.
* Storage in its own table of all the magnitudes managed by QGISRed, specifying the units and decimals to be displayed in the different systems of units and according to the case.
* Creation of your own Legend Editor to customize ranges or classes, colors and sizes of all the legends managed by QGISRed.
* Wizards to customize legends automatically.
* Addition of a new menu and a new toolbar to house the new options aimed at querying data and results.
* Reorganization of the layers of the Queries group, and the storage of the corresponding shp files in the project folder structure.
* New tool to locate any element on the map through its Id and identify connected elements, with the option to navigate through them.
* New panel to observe the data and results of any selected network element. Synchronization of the results with the current moment of the simulation.
* New dialog to create thematic maps of some magnitudes associated with the different types of elements managed by QGISRed.
* New panel to locate elements on the map that meet certain criteria in relation to data or results. Synchronization with the results for the current moment of the simulation.
* Improvement of the format in which the INP file is exported from QGISRed, similar to what would be exported from the EPANET Toolkit.
* Replacement of the EPANET 2.2 calculation engine with the new version 2.3, up to the most recent revision 2.3.5.
* Reading the results of a simulation directly from the EPANET binary files for faster and more agile navigation.
* Incorporation of the Status Report to the results panel in a new tab, always accessible.
* Export of all simulation results to a structured CSV file.
* New option to display various statistics about the results throughout the entire simulation period.
* New window to show the evolution curve over time of any magnitude of an element throughout the simulation period. Possibility of superimposing several curves for the same or different magnitude.
* Improvements in the Demand Builder for specific demands. Review of algorithms and automatic loading of links. New topic for demand points.
* Review of the tool for identifying hydraulic sectors and detecting isolated consumption.
* Review of the algorithm to identify closed. Detection of isolated consumption.
* New options at the project level to transfer the demands of the connections to the nodes. Classification of demands by employers.
* Compatibility of version 0.18 with new versions of QGIS 4.0.
* Translation of all QGISRed dialogs, panels, messages and layer names into Spanish.
* Redesign of all the icons managed by QGISRed with a more uniform and pleasant appearance.
* Web hosting of the provisional QGISRed manual in English and Spanish for online consultation through the GitBook collaborative platform.
* Mention to the Inter-American Development Bank (IDB) for the financial support of all the improvements made in this version 0.18.

**Corrections**:
* Resolved an issue when loading field data related to the decimal separator.
* Fixed an error that prevented demands from isolated areas from being canceled.
* Limitation on the size of the Description field, used to report on the demands of the connections loaded at each node.

### Version 0.17 (January 2026)
**QGis Versions**: 3.2-3.99

**News**:
* New closed scan tool, with multiple options.
* Display results of up to 13 states for pipes, valves and pumps.
* Transfer of states and qualities for chaining simulations in successive periods.
* New options to reset roughness, elevations and diameters in the scenario builder.
* New option to export and import scenarios with the Epanet format.
* New features in the project manager (sort, export, delete and rename).
* New buttons to open or save projects.
* New option to import a QGISRed project.
* Changes to icons and names in some menu options.
* Improved precision when writing numerical values ​​in shapes.
* Improvement in the message when downloading the necessary dependencies.

**Corrections**:
* Corrected error when interpolating dimensions when the point falls on one of the ends of the mesh.
* Corrected error when distributing demands in proportion to the length of the pipes.
* Fixed error when loading demands from a layer of sectors.
* Fixed error when importing INPs with sources without a defined pattern.
* Fixed errors when importing INP related to Times and Temporary Rules.
* Fixed error when exporting INPs with very long descriptions.
* Corrected error with the decimal symbol in the PDA model options.
