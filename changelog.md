# 📜 Changelog

Stay up to date with the latest QGISRed improvements.

### Version 0.19

**News**:

* Complete restructuring of the Statistics panel: new Setup/Report tabs, histogram with floating window and statistic selector on the Y axis, and second cross classification with results matrix.
* New display options in the Results panel: size proportional to value in nodes and pipes, and optional black outline in node markers.
* Improved map labels: show item type and Id on the first line and value with units on the second.
* Map tooltips visible on all active layers managed by QGISRed, regardless of the layer selected in the legend.
* Quick time evolution directly from the Results dock, without having to open the Time Series panel.
* Improvements in the Time Series panel: new tank magnitudes (Volume and TankSpill), cursor synchronized with the value table, table copy with double header (name and unit), export and import of the chart configuration and support for multiple simultaneous windows.
* Simulation progress dialog with option to not be shown again (configurable from Project Properties).
* Improved simulation error handling: the EPANET report is automatically displayed in the log when an error occurs, and unhandled errors are logged instead of failing silently.
* Specific notice when results files are locked by another application.
* Demand Builder: restructuring of the patterns section by sectors with two exclusive modes (import external SHP / use project layer).
* Demand Builder: sector efficiency section with two work modes, and new options to correct category efficiencies and sector patterns to meet global objectives.
* Demand Builder: automatic distribution of missing demand percentages in section layers.
* New layer of isolated connections with non-zero demand generated by analyzing hydraulic segments.
* Distribution tree: The root node is identified with `NodeType = "ROOT"` in the resulting layer of nodes.
* Renaming identifier fields in the project's SHP layers (e.g. `Id` → `JunctionID`, `PipeID`, etc.). Projects created with previous versions remain compatible thanks to the inherited name table.
* Unassigned category renamed from "Undefined" to **"Uncategorized"** in the Demand Builder and layer legend.
